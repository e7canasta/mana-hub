# mana-hub Roadmap

## Vision

Build a System of Record for adult residential care monitoring that:
- Persists all clinical data (residents, episodes, evidence, notes)
- Provides a typed Kotlin DSL for external components
- Supports the director médico's daily workflow
- Enables BDD-driven development with context groups

## Sprint Overview

| Sprint | Name | Duration | Focus |
|--------|------|----------|-------|
| [Sprint 01](sprint-01-core.md) | Core + Residence + Population | 2 weeks | Infrastructure, master data |
| [Sprint 02](sprint-02-monitoring.md) | Policy + Surveillance | 2 weeks | Monitoring config, episodes |
| [Sprint 03](sprint-03-observation.md) | Observation + Evidence | 2 weeks | Events, clips, timelines |
| [Sprint 04](sprint-04-care.md) | Care + History | 2 weeks | Rounds, notes, timeline |
| [Sprint 05](sprint-05-client-dsl.md) | Client DSL | 2 weeks | Kotlin client library |
| [Sprint 06](sprint-06-blueprints.md) | Blueprints + BDD | 2 weeks | Scenarios, specs, docs |
